# 逻辑完整性验证规则

> **版本**: v0.1
> **更新日期**: 2026-03-27

---

## 一、结论支撑规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| L-01 | 每个核心结论必须有≥1个数据/论据支撑 | 高 |
| L-02 | 支撑数据必须与结论直接相关 | 高 |
| L-03 | 定量结论必须有定量数据支撑 | 高 |
| L-04 | 趋势判断必须有时间序列数据 | 中 |

**输出模板**：
```
L{行号}: "{结论关键词}"无支撑
L{行号}: 结论与L{数据行号}不匹配
```

---

## 二、推理连贯规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| L-05 | 论证链条A→B→C必须完整，不可跳级 | 中 |
| L-06 | 隐含假设必须显性说明 | 中 |
| L-07 | 推理步骤间必须有逻辑关联 | 中 |

**输出模板**：
```
L{起}→L{止}: 推理跳跃，缺中间论证
L{行号}: 隐含"{假设内容}"假设未说明
```

---

## 三、因果关系规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| L-08 | 因果判断需有实验/机制证据，相关性≠因果 | 高 |
| L-09 | 时序关系不等于因果关系 | 中 |
| L-10 | 因果方向需明确，避免倒果为因 | 高 |

**输出模板**：
```
L{行号}: "{因果陈述}"仅有相关性
L{行号}: 因果方向存疑
```

---

## 四、一致性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| L-11 | 同一文档内结论不得自相矛盾 | 高 |
| L-12 | 同一指标在不同位置数值必须一致 | 高 |
| L-13 | 立场/观点不得前后漂移 | 中 |

**输出模板**：
```
L{行号}+L{行号}: 结论矛盾
L{行号}与L{行号}: {指标}不一致({值1} vs {值2})
```

---

## 五、边界合理规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| L-14 | 行业结论需≥3个案例支撑，单案例不可推全局 | 中 |
| L-15 | 长期趋势预测需≥12个月数据 | 中 |
| L-16 | 外推预测需说明边界条件 | 低 |

**输出模板**：
```
L{行号}: 仅{N}案例，不足以推"{结论}"
L{行号}: {时长}数据推{预测时长}，外推过度
```
