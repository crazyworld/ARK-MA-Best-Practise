# 数据一致性验证规则

> **版本**: v0.1
> **更新日期**: 2026-03-27

---

## 一、来源标注规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-01 | 外部数据必须标注来源 | 中 |
| D-02 | 来源必须包含机构名称 | 中 |
| D-03 | 来源必须包含数据时间 | 低 |
| D-04 | 来源格式必须统一 | 低 |

**输出模板**：
```
L{行号}: 数据无来源
L{行号}: 来源缺{缺失项}
L{行号}+L{行号}: 来源格式不一致
```

---

## 二、来源可信规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-05 | 核心数据来源必须为A/B级 | 高 |
| D-06 | C级来源需交叉验证 | 中 |
| D-07 | D级来源不可作为结论依据 | 高 |
| D-08 | 来源链接必须有效 | 中 |

**来源层级**：
| 层级 | 类型 | 示例 |
|------|------|------|
| A | 官方/监管 | 国家统计局、证监会、财报 |
| B | 权威机构 | 艾瑞、QuestMobile、Sensor Tower |
| C | 媒体/二手 | 新闻报道、行业文章 |
| D | 不明/自述 | 无法验证 |

**输出模板**：
```
L{行号}: 来源为{级别}级，{问题描述}
L{行号}: 来源链接失效
```

---

## 三、数值一致规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-09 | 同一指标不同位置数值必须一致 | 高 |
| D-10 | 百分比加总必须等于100%（±1%容差） | 中 |
| D-11 | 计算结果必须与原数据一致 | 高 |
| D-12 | 同一单位体系内数值必须自洽 | 高 |

**输出模板**：
```
L{行号}+L{行号}: {指标}不一致({值1} vs {值2})
L{行号}: 占比加总≠100%(实为{值})
L{行号}: {计算项}计算错误(应为{正确值})
```

---

## 四、时效性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-13 | 财务数据时效≤1年 | 中 |
| D-14 | 市场数据时效≤6个月 | 中 |
| D-15 | 用户数据时效≤3个月 | 中 |
| D-16 | 数据时间点必须与报告要求匹配 | 中 |

**输出模板**：
```
L{行号}: 数据过期({数据年份}年数据)
L{行号}: 时效超限({实际时效} > {要求时效})
```

---

## 五、合理性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-17 | 增长率应在合理范围（-50%~200%） | 中 |
| D-18 | 占比必须在0%-100%之间 | 高 |
| D-19 | 数值量级必须合理 | 高 |
| D-20 | 排名/排序必须符合数值大小 | 中 |

**输出模板**：
```
L{行号}: {指标}{值}异常
L{行号}: 占比{值}超范围
L{行号}: 量级存疑({值} vs 行业均值{参考值})
```

---

## 六、交叉验证规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-21 | 核心数据需≥2个来源交叉验证 | 中 |
| D-22 | 不同来源数据差异≤10%视为一致 | 低 |
| D-23 | 差异>20%需标注并说明 | 中 |

**输出模板**：
```
L{行号}: 核心数据仅单一来源
L{行号}: 来源间差异{差异值}，需说明
```
