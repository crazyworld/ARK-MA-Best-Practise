# Check 格式规范规则

> **版本**: v1.0（2026-06-26）
> **状态**: 生效
> **来源**: 改编自 `KS_Validation_Rules/格式规范规则.md`（F-06~F-15，剔除标点符号和排版规则）
> **用途**: Check 角色在执行 Topic 专项清单时的补充判断规则，不替代 Topic 清单

---

## 一、数字格式规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-06 | 同一指标单位必须一致（亿/万不混用） | 中 |
| F-07 | 同类数字精度必须一致 | 中 |
| F-08 | 百分比格式统一（15%或15.0%） | 低 |
| F-09 | 大数使用千分位或中文单位 | 低 |

**输出模板**：
```
L{行号}+L{行号}: 单位不一致({单位1}/{单位2})
L{行号}+L{行号}: 精度不一致({格式1}/{格式2})
```

---

## 二、文档结构规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-10 | 标题层级递进，不可跳级（H1→H3） | 中 |
| F-11 | 同级标题格式必须一致 | 低 |
| F-12 | 必要章节不可缺失 | 中 |

**输出模板**：
```
L{行号}: H{N}→H{M}跳级
L{行号}+L{行号}: 同级标题格式不一致
缺失: {章节名}
```

---

## 三、引用标注规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-13 | 外部数据必须标注来源 | 中 |
| F-14 | 来源格式必须统一 | 低 |
| F-15 | 来源信息必须完整（机构+时间） | 低 |

**输出模板**：
```
L{行号}: 数据无来源
L{行号}+L{行号}: 来源格式不一致
L{行号}: 来源缺{缺失项}
```
