# BlueFocus Hotspot Web Report

> **与相似 skill 分工（Ada 接入补充）**：本 skill 仅负责 Topic6 热点报告的**网页版 HTML 生成与发布（Phase G）**，输入是已定稿的报告内容；`blueai-hotspot-weekly-skill`（社媒舆论周报原始数据处理）与本 skill 无调用关系、不同 Topic；`Export_to_Feishu` 负责飞书文档发布（Phase F），本 skill 负责独立 HTML 站点发布，二者输出格式不同、阶段不同，不互相替代。

> **Topic6 Phase G 正文来源**：网页正文以 HC3 定稿飞书文档为准——先用 `scripts/fetch_report_md.py --doc <docx> --out report_feishu.md --fallback <本地合并报告.md>` 把飞书文档块还原为 Markdown（用户在飞书里改的文字/表格随之进入网页）；读取失败或还原不完整（无章节、章节少于本地、表格或链接整体丢失）时自动回退本地稿，stdout 给出 `source=local_fallback` 与原因，不阻断。
>
> **Topic6 Phase G 固定入口**：输入是上一步得到的报告 Markdown 时，必须用 `scripts/md2source.py <report.md> <source.json>` 确定性生成 source.json（链接→`block.links`、`[配图：待补充]` 跳过、案例 `链接：` 并入原始热点、热度列去"分"），禁止手工拼 source.json；Workflow 第 3 步的"转换"即由该脚本完成。营销观察案例统一渲染为左文右图卡片（`docx-grid-block`）：配图由 `scripts/fetch_case_images.py` 从 HC3 定稿飞书文档下载（`案例 N：` 标题后的首张图片 → `case-N.*`），经 `md2source.py --case-images <dir>` 挂载；缺图案例渲染"配图待补充"占位，非阻断。下方 Workflow 第 4 步"取不到图就停"对 Topic6 不适用。

Create a self-contained HTML hotspot report from this template. Keep the retained source directory unchanged; always work on a copy.

## Workflow

1. Read `artifact-template.json` and resolve `reference`. Run `node <skill-directory>/scripts/validate-template-assets.mjs` and stop if any retained PNG, JPEG, or TTF file is missing or invalid. Copy the validated retained source directory into a new working directory; do not edit the retained source in place.
2. Read `assets/source/DESIGN_SPEC.md` completely before changing content or styles. When the source contains any images, also read [references/document-image-extraction.md](references/document-image-extraction.md) completely. Use `source.example.json` as the input-schema reference; never edit the retained source in place.
3. Convert the user's Markdown, document text, Feishu content, or JSON into a UTF-8 block array compatible with `source.example.json`. Preserve every heading, paragraph, table value, list item, link, image, date, platform name, and heat score exactly. Ask for missing factual values rather than inventing them. When a Feishu extractor emits `•` as a standalone structural line before a `docx-text-block`, omit only that marker; preserve real `docx-bullet-block` list items. Derive navigation copy from each source H1 after removing its chapter number: preserve the title verbatim when it is 5 Chinese characters or fewer; when it exceeds 5 characters, summarize its meaning as an accurate 4-character Chinese label.
4. Extract every case image from the user's source document. This is a provenance requirement, not a visual suggestion. Never call image-generation tools or create substitute artwork. For Feishu/Lark, fetch both `rawContent` and the complete blocks tree, obtain each image token from its block, and download the original media binary with the authenticated connector/API. Set the same `docx-grid-block.images[0].src` to the downloaded local file or Data URL. Never leave a browser-session `blob:` URL and never reuse retained W32 `case-*.jpg` files for a new case. Do not remove or hide a block merely because a partial browser viewport has not loaded it: the complete blocks tree is authoritative. If the Agent cannot retrieve the source-document image binary, stop and request a document export or the original image.
5. Save the normalized content as `source.json`. Weekly versus monthly is determined only by the period label in the introductory `数据周期：<label>（…）` quote (e.g. `2026-W44` → weekly, `2026年10月` → monthly); month mentions in body text never change it. The builder selects `title-weekly.png` or `title-monthly.png` accordingly.
6. Keep the retained HTML structure, CSS, JavaScript, logo, fonts, icons, gradients, charts, heat bars, tabs, sticky navigation, cards, and responsive rules unless the user explicitly requests a visual change. Poppins covers Latin letters and numerals; Chinese uses the cross-platform `Noto Sans SC` / `Source Han Sans SC` stack with platform fallbacks. Do not embed a full CJK family unless the user explicitly requires exact Chinese typography and the final self-contained HTML stays within the upload size limit. For data-card list fields, remove vertical separators while retaining source wording and order. “具体热搜”“具体热搜·平台·热度值” use plain text with no decorative bullet; “主要驱动话题” alone uses a small round bullet in the same color as its text. Every driver item, including the first, must retain a 10px left inset so text never overlaps its bullet. In “品牌合作动态” cards, omit generic “事件 / 合作事件” pills and retain only the industry pill. Marketing-observation cases must turn their source text after “原始热点：” into the blue outbound link; when the source also contains a standalone `链接：URL` line, use it as the link target but do not render that URL separately. Keep the Hero background layer at `z-index: 0` within the Hero (with content above it), but leave the Hero surface transparent so the page canvas gradient continues through it; never rely on a negative z-index background layer or add an opaque Hero-only fallback that creates a horizontal seam in an iframe or mobile WebView.
7. Before building, run `node <skill-directory>/scripts/validate-case-image-sources.mjs source.json`. Then run `node --check build-report.mjs` followed by `node build-report.mjs source.json index.html`, and finally run `node <skill-directory>/scripts/validate-rendered-content.mjs source.json index.html`. Treat any image-validation, content-coverage, or “Missing reusable image” error as an input-preparation failure: retrieve the complete source block data and fix the affected `images.src` or block mapping; do not generate an image, delete the field, renumber cases, or fall back to a template image. The result must remain a self-contained HTML file.
8. Verify content fidelity, source links, title selection, ranking cards, chart hover values, tabs, sticky navigation, 390px mobile layout, absence of horizontal overflow, minimum 12px text, and that every marketing-observation image matches the same case in the source document. Check mobile Hero continuity at 390px and 600px: no pure-color seam above the Hero background, and the title/date stack before either clips in an embedded WebView. Between 601px and 1140px, primary navigation must distribute its labels without clipping; permit horizontal scrolling only after usable padding has been reduced. Check industry ranking cards at 768, 1024, and 1440px: use a card-container breakpoint to stack metrics before titles or topics can collide, while wide cards retain the two-column editorial layout; at 520–939px keep rank/title/count and heat on one header row and render driver topics in two columns. Platform event cards at 521px and above use an explicit two-row header grid: rank plus title on row one, then total plus heat on row two; rank must vertically center to the title text block (single or multi-line), never top align. Keep the title-to-metric row gap compact (about 6px desktop/tablet and 7px phone) without forcing an overlap. Apply the retained 8px upward optical adjustment to award SVGs and a 4px adjustment to compact rank circles because their visual centers differ. At 680px and above, keep the event title on one line to use available header space. Below 520px, keep total and heat aligned to the title column instead of resetting them to the rank gutter. Marketing node-summary cards use each individual card as their query container: at 420px and above place node title/count on the left and heat on the right within one header row; below 420px they stack with heat left-aligned. Never use a two-card grid's combined width to choose a child card layout. For every hot-search list, use an auto-fit grid with a 220px minimum column: consume available space with as many columns as fit, then fall back to one left-aligned column. Platform hot-keyword cards also place ranking/title/heat on one header row from 420px upward. Confirm the rendered case count equals the active source-case count and every substantive paragraph/table value is present. Confirm that the final HTML contains no `blob:` URLs.
9. Do not upload an HTML snapshot. In Topic6 the only web delivery is the Miaoda (妙搭) publish in Phase H; the sandbox has no snapshot API key. `scripts/upload-html.mjs` and `references/html-snapshot-upload.md` are retained for reference only and must not be run (including `--dry-run` / `--setup-key`), and you must not ask the user to set up a key.
10. Return the finished local `index.html` and working directory.

## Fidelity

Preserve the source application's layout, visual hierarchy, typography, title artwork, card system, data visualizations, interactions, links, current report images, and responsive behavior.

User instructions control requested content and explicit deviations. The retained reference controls layout and formatting where the user has not requested a change.
