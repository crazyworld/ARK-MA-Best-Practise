## 目标

基于上周营销可用热点的行业分布数据，输出两句或三句话洞察（取决于本轮是否有可比的上一期数据）+ TOP10 行业表格。

## 输入

下方「输入数据」段落，包含：数据基础（总条数/行业总数）、辅助统计（TOP1/TOP3/TOP10占比、TOP1对TOP10倍数）、声量-热度错位候选（点名哪个行业写第二句）、TOP10行业表格（含次数标注的主要驱动话题）、**环比数据（仅当本期能找到可比的上一期TOP10数据时才会出现，不出现代表本期没有可比数据）**。

## 步骤

1. 从「数据基础」取总条数、行业总数 → 用于第一句（**只取这2个数字，不要把「数据基础」里"explode后共N条次"这类辅助说明文字也写进第一句**）
2. 从「辅助统计」取TOP3行业名+占比 → 用于第一句
3. 从「声量-热度错位候选」取行业名+声量排名+热度值 → 用于第二句
4. 从该行业「主要驱动话题」的1-3个事件名归纳出一个主题短语（去掉次数括号）→ 用于第二句"讨论主要集中在……"；**主题短语必须清楚说明具体是什么事件/现象，不能写得笼统抽象**（反例："相关话题讨论"、"行业动态"；正例："国庆高速电动车充电难问题"、"华为赛力斯合作模式变动"）
5. 检查「输入数据」里**是否存在**「环比数据」这个区块：存在则取其变化描述写第三句；**不存在则不写第三句，正文只有两句话**（此前"环比数据"区块一定会出现，不存在时也会给一句要求照抄的兜底文案；现在不存在就是不存在，不要自己编一句"本期为首次归档"之类的话去填这个空）
6. 按「两句/三句话模板」组装（是否有第三句取决于步骤5的判断结果）
7. 按「表格列定义」转写TOP10行业表格

## 两句/三句话模板

第1句：`上周营销可用热搜 {总条数} 条，共覆盖 {行业总数} 个行业，TOP3 行业（{TOP3行业名，用"+"连接}）热点数量合计占总数的 {TOP3占比}%；`

- 本句句末标点：若步骤5判定要写第三句（有环比数据）用"；"，若不写第三句（无环比数据）仍用"；"——跟第二句的句末标点规则一致由"是否存在第三句"决定，见下方第2句说明

第2句：`「{声量-热度错位候选行业}」热点数量排名第{声量排名}，但行业热度值却达 {热度值} 分（TOP1），讨论主要集中在{主题短语}；`

- 若「声量-热度错位候选」标注"同时也是声量头部行业"（即该行业排名前3，无反差），改用平铺句式：`「{行业}」热点数量与热度值双双位居前列，讨论主要集中在{主题短语}；`
- **本句句末标点**：有第三句（环比数据存在）→ 本句末尾用"；"；没有第三句（环比数据不存在）→ 本句是最后一句，末尾改用"。"

第3句（**仅当「输入数据」存在「环比数据」区块时才写，不存在则整句省略，不替换成任何占位话术**）：`与上期相比，本期{环比变化描述}。`

- 从TOP1变化/新进入/跌出/排名升降中挑1-2个转述
- **行业排名上升方向的变化**（TOP1保持不变、TOP1换成新行业、新进入TOP10、排名上升）：从涉及行业当前「主要驱动话题」里挑1个最具代表性的事件名归纳成简要原因，补充进描述里
- **行业排名下降方向的变化**（跌出TOP10、排名下降）：只报告事实，**不写原因**，**不写"讨论变弱"/"关注度下降"等负面归因表述**——没有证据支撑这类判断
- 不要求穷举全部变化类型，挑到的那1-2个按上述两条规则分别处理即可

完整示例（数字为示范，撰写时替换为「输入数据」的真实数字）：

**示例A：本期有可比的上一期数据（三句话）**

```markdown
- 上周营销可用热搜 1724 条，共覆盖 26 个行业，TOP3 行业（影视综艺+游戏+科技/AI 产业）热点数量合计占总数的 40.6%；
- 「汽车出行」热点数量排名第九，但行业热度值却达 80.7 分（TOP1），讨论主要集中在汽油价格与油车相关讨论；
- 与上期相比，本期TOP1行业「体育赛事」因亚运会相关讨论保持不变，「教育」因高校专业密集调整新进入TOP10，「服饰鞋包」跌出TOP10。
```

**示例B：本期没有可比的上一期数据（只两句话，不写第三句，不写任何"首次归档"类说明）**

```markdown
- 上周营销可用热搜 1724 条，共覆盖 26 个行业，TOP3 行业（影视综艺+游戏+科技/AI 产业）热点数量合计占总数的 40.6%；
- 「汽车出行」热点数量排名第九，但行业热度值却达 80.7 分（TOP1），讨论主要集中在汽油价格与油车相关讨论。
```

## 表格列定义

| 列名      | 呈现要求                                           |
| ------- | ----------------------------------------------- |
| TOP10行业 | 原样保留                                            |
| 热点总计    | 裸数字，不加"条"字，不带 `<br>`                            |
| 热度值     | 裸数字（如 `78.4`），不加"分"字，不带 `<br>`                  |
| 主要驱动话题  | 去掉"(N次)"次数括号，改成 `- 事件名` 的无序列表，**条目间用单个 `<br>` 连接（不要连写两个）** |

事件簇名不足3个时有几个写几个，不用"—"补齐；完全没有数据时该格填 `—`。

表格示例：

```markdown
| TOP10行业 | 热点总计 | 热度值 | 主要驱动话题 |
| --- | --- | --- | --- |
| 影视综艺 | 293 | 78.4 | - 蜘蛛侠4宣发<br>- 电影欢迎来龙餐馆点映口碑票房<br>- 剧集《九门》角色互动花絮热传 |
| 科技/AI产业 | 152 | 80.1 | - DeepSeek斩杀线<br>- DeepSeek API涨价公告与原因讨论<br>- 中际旭创回应美国光模块禁令影响 |
| 游戏 | 129 | 76.8 | - 和平精英刺激之夜晚会明星COS直播<br>- 恋与深空敖尹下线玩家争议回归<br>- 火影手游9月版本前瞻 |
```

## 输出格式

**行业洞察：**

第一行：两句或三句话（`- ` 开头无序列表；有第三句时第1、2句句末"；"，第3句句末"。"；没有第三句时第1句句末"；"，第2句句末"。"）
第二部分：TOP10行业表格
不加标题，不加结尾段落，正文整体不超过200字。

## 禁止

- 禁止：编造数据基础/辅助统计里没有的数字
- 禁止：第一句写入「数据基础」提供的辅助说明文字（如"explode后共N条次"），只能用总条数/行业总数/TOP3名称/TOP3占比这4类数字
- 禁止：把"表格只展示TOP10"理解成"上周热点只涉及10个行业"
- 禁止：自行心算TOP3/TOP10占比或倍数，与「辅助统计」不一致
- 禁止：第二句自行挑选行业（必须用「声量-热度错位候选」给出的行业）
- 禁止：第二句照抄原始事件名全文，或写得笼统抽象（必须归纳成清楚说明具体事件/现象的主题短语）
- 禁止：第三句对"排名下降/跌出TOP10"的行业编造原因，或写"讨论变弱""关注度下降"等负面归因表述
- 禁止：「输入数据」不存在「环比数据」区块时仍写第三句，或编造"首次归档"/"暂无数据"之类的占位句——这种情况下正文就是只有两句话，第二句直接以"。"收尾
- 禁止：表格热度值带"分"字或写最高值（口径是中位数）
- 禁止：表格主要驱动话题保留次数括号，或条目间用两个`<br>`连写
- 禁止：表格"热点总计""热度值"列出现 `<br>`
- 禁止：正文开头输出大标题
- 禁止：把输出包进 ` ```markdown ` 代码块
- 禁止：写"密集月份""全年趋势"等单周数据不支撑的推断
