# 数据审计能力

> **层级**: L2 能力层
> **加载**: 审计研究报告/数据文档时加载
> **行数上限**: ~150行

---

## 一、审计目标

检查输出内容的数据质量：来源可信、数值一致、时效有效。

---

## 二、检查维度

| 维度 | 检查点 | 典型问题 |
|------|--------|----------|
| **来源标注** | 数据是否有来源 | 无来源、来源不完整 |
| **来源可信** | 来源是否可信 | 来源不权威、来源失效 |
| **数值一致** | 同一指标是否一致 | 前后矛盾、计算错误 |
| **时效性** | 数据是否过期 | 数据过旧、时间点不符 |
| **合理性** | 数值是否在合理范围 | 异常值、量级错误 |

---

## 三、检查规则

### 3.1 来源标注

**规则**：外部数据必须标注来源（机构+时间）

**问题模式**：
- 数据无任何来源标注
- 来源信息不完整（缺机构或时间）
- 来源格式不统一

**输出示例**：
```
L156: 数据无来源
L200: 来源缺时间
L89+L230: 来源格式不一致
```

### 3.2 来源可信

**规则**：来源必须为权威机构或一手数据

**可信来源层级**：
| 层级 | 来源类型 | 示例 |
|------|----------|------|
| A | 官方/监管 | 国家统计局、证监会、上市公司财报 |
| B | 权威机构 | 艾瑞、QuestMobile、Sensor Tower |
| C | 媒体/二手 | 新闻报道、行业文章 |
| D | 不明/自述 | 无法验证来源 |

**输出示例**：
```
L156: 来源为D级，不可信
L200: 来源链接失效
```

### 3.3 数值一致

**规则**：同一指标在不同位置数值必须一致

**问题模式**：
- 同一指标前后数值不同
- 百分比加总不等于100%
- 计算结果与原数据不符

**输出示例**：
```
L89+L230: 市场规模不一致(150亿 vs 145亿)
L156: 占比加总≠100%(实为98%)
L200: 增长率计算错误(应为12%非15%)
```

### 3.4 时效性

**规则**：数据时间点必须符合报告要求

**时效标准**：
| 数据类型 | 最大时效 |
|----------|----------|
| 财务数据 | ≤1年 |
| 市场数据 | ≤6个月 |
| 用户数据 | ≤3个月 |
| 实时数据 | ≤1个月 |

**输出示例**：
```
L156: 数据过期(2023年数据用于2026年报告)
L200: 时间点与报告要求不符
```

### 3.5 合理性

**规则**：数值必须在合理范围内

**问题模式**：
- 增长率超过合理范围（如>200%）
- 占比超过100%或为负
- 量级明显错误（亿/万混淆）

**输出示例**：
```
L156: 增长率500%异常
L200: 占比>100%
L89: 量级存疑(15亿 vs 行业均值150亿)
```

---

## 四、输出格式

```markdown
## 数据审计 - {文件名}

| 位置 | 问题 | 严重度 |
|------|------|--------|
| L156 | 数据无来源 | 中 |
| L89+L230 | 市场规模不一致 | 高 |
| L200 | 数据过期(2023) | 中 |
```

---

## 五、严重度判定

| 级别 | 条件 |
|------|------|
| **高** | 核心数据无来源、数值矛盾影响结论、来源不可信 |
| **中** | 来源不完整、数据过期、非核心数据问题 |
| **低** | 来源格式不一致、轻微时效问题 |

---

## 六、外部验证触发

以下情况需调用秘塔搜索验证：
- 核心数据来源为C/D级
- 数据与常识明显不符
- 用户明确质疑

---

## 七、案例库

### 7.1 数据无来源

**原文**: "2025年中国Roguelike游戏市场规模达到150亿元"（无来源）

**输出**: `L156: 数据无来源`

### 7.2 数值不一致

**L89**: "移动端占比78%"
**L230**: "移动端占比75%"

**输出**: `L89+L230: 移动端占比不一致(78% vs 75%)`

### 7.3 数据过期

**原文**: "根据2023年数据，市场增长率为25%"（报告为2026年）

**输出**: `L200: 数据过期(2023年数据)`

### 7.4 计算错误

**原文**: "从100亿增长到120亿，增长率为25%"

**输出**: `L156: 增长率计算错误(应为20%)`
