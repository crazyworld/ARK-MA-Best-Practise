# 格式审计能力

> **层级**: L2 能力层
> **加载**: 审计文档格式规范时加载
> **行数上限**: ~100行

---

## 一、审计目标

检查输出文档的格式规范：标点统一、数字规范、结构清晰。

---

## 二、检查维度

| 维度 | 检查点 | 典型问题 |
|------|--------|----------|
| **标点符号** | 中英文标点是否统一 | 混用、错用 |
| **数字格式** | 单位、精度是否一致 | 单位混乱、精度不一 |
| **文档结构** | 标题层级是否规范 | 层级跳跃、结构混乱 |
| **引用标注** | 数据来源是否标注 | 缺来源、格式不一 |
| **排版规范** | 空行、缩进是否一致 | 排版混乱 |

---

## 三、检查规则

### 3.1 标点符号

**规则**：中文语境用中文标点（全角），英文/代码用英文标点（半角）

**问题模式**：
- 中文句子用英文逗号/句号（半角混入）
- 全角半角括号混用
- 引号不配对
- 全角空格混入

**输出示例**：
```
L156: 半角逗号混入中文
L230: 全角半角括号混用
L89: 半角句号混入中文
```

### 3.2 数字格式

**规则**：同类数字格式统一（单位、精度、分隔符）

**问题模式**：
- 同一指标单位不一致（亿/万混用）
- 精度不一致（15% vs 15.3%）
- 大数分隔不一致

**输出示例**：
```
L89+L156: 单位不一致(亿/万)
L200+L340: 精度不一致(整数/小数)
```

### 3.3 文档结构

**规则**：标题层级递进，不跳级

**问题模式**：
- H1直接到H3
- 同级标题格式不一致
- 缺少必要章节

**输出示例**：
```
L45: H1→H3跳级
L120+L180: 同级标题格式不一致
```

### 3.4 引用标注

**规则**：数据必须标注来源，格式统一

**问题模式**：
- 数据无来源标注
- 来源格式不一致
- 来源信息不完整

**输出示例**：
```
L67: 数据无来源
L89+L156: 来源格式不一致
```

### 3.5 排版规范

**规则**：空行、缩进、列表格式统一

**问题模式**：
- 段落间空行不一致
- 列表符号混用
- 缩进层级混乱

**输出示例**：
```
L100-L120: 空行不一致
L200: 列表符号混用
```

---

## 四、输出格式

```markdown
## 格式审计 - {文件名}

| 位置 | 问题 | 严重度 |
|------|------|--------|
| L156 | 英文逗号混入中文 | 低 |
| L89+L156 | 单位不一致 | 中 |
| L67 | 数据无来源 | 中 |
```

---

## 五、严重度判定

| 级别 | 条件 |
|------|------|
| **高** | 数据无来源、结构严重混乱 |
| **中** | 单位/精度不一致、来源格式不统一 |
| **低** | 标点混用、排版细节 |

---

## 六、案例库

### 6.1 全角半角混用

**原文**: "市场规模达到150亿,同比增长15%。"（逗号为半角）

**输出**: `L156: 半角逗号混入中文`

### 6.2 括号混用

**原文**: "头部产品（如弹壳特攻队)占比超过60%"

**输出**: `L89: 全角半角括号混用`

### 6.2 单位不一致

**L89**: "市场规模150亿元"
**L156**: "市场规模15000万元"

**输出**: `L89+L156: 单位不一致(亿/万)`

### 6.3 数据无来源

**原文**: "用户付费率达到8.5%"（无来源标注）

**输出**: `L67: 数据无来源`
