# 格式规范验证规则

> **版本**: v0.1
> **更新日期**: 2026-03-27

---

## 一、标点符号规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-01 | 中文语境使用全角标点 | 低 |
| F-02 | 英文/代码使用半角标点 | 低 |
| F-03 | 全角半角不可混用 | 低 |
| F-04 | 括号必须配对且格式一致 | 低 |
| F-05 | 引号必须配对 | 低 |

**输出模板**：
```
L{行号}: 半角{标点}混入中文
L{行号}: 全角半角括号混用
```

---

## 二、数字格式规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-06 | 同一指标单位必须一致（亿/万不混用） | 中 |
| F-07 | 同类数字精度必须一致 | 中 |
| F-08 | 百分比格式统一（15%或15.0%） | 低 |
| F-09 | 大数使用千分位或中文单位 | 低 |

**输出模板**：
```
L{行号}+L{行号}: 单位不一致({单位1}/{单位2})
L{行号}+L{行号}: 精度不一致({格式1}/{格式2})
```

---

## 三、文档结构规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-10 | 标题层级递进，不可跳级（H1→H3） | 中 |
| F-11 | 同级标题格式必须一致 | 低 |
| F-12 | 必要章节不可缺失 | 中 |

**输出模板**：
```
L{行号}: H{N}→H{M}跳级
L{行号}+L{行号}: 同级标题格式不一致
缺失: {章节名}
```

---

## 四、引用标注规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-13 | 外部数据必须标注来源 | 中 |
| F-14 | 来源格式必须统一 | 低 |
| F-15 | 来源信息必须完整（机构+时间） | 低 |

**输出模板**：
```
L{行号}: 数据无来源
L{行号}+L{行号}: 来源格式不一致
L{行号}: 来源缺{缺失项}
```

---

## 五、排版规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| F-16 | 段落间空行一致 | 低 |
| F-17 | 列表符号统一（-或·） | 低 |
| F-18 | 缩进层级一致 | 低 |

**输出模板**：
```
L{起}-L{止}: 空行不一致
L{行号}: 列表符号混用
```
