## 方案 QC 规则（KS_QC_Rules/）— P0 强制读取

### 用途

Planner 方案质量审计的**唯一规则来源**。由 Planner spawn Validator 时在 Phase 2 使用。

### 文件状态

| 文件 | 状态 | 说明 |
|------|------|------|
| `KS_QC_Rules_v2.md` | ✅ 生产可用 | 需求一致性(P0) → 源头一致性(P0) → 数据准确性 → 专业内容 → 逻辑错误 → 结构问题 → 基础错误 → 合规风险 |

### 调用时机

- Planner spawn Validator 执行方案 QC 时，**第一步**读取此文件
- Variable ID 校验为条件触发：方案含编号时全量校验，无编号时跳过

## 知识积累原则

### 何时更新规则库

1. **发现新问题类型**：审计中发现的新问题类型，补充到规则库
2. **误报修正**：因规则不当导致的误报，调整规则逻辑
3. **人工反馈**：用户/专家对审计标准的修正意见

### 何时更新检查清单

1. **新输出类型**：新增Agent或新输出类型，创建对应清单
2. **遗漏问题**：因清单遗漏导致问题漏检，补充检查项
3. **效率优化**：删除低价值检查项，提升审计效率
