# 商业问题验证规则

> **版本**: v0.1
> **更新日期**: 2026-03-27

---

## 一、切题度规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| B-01 | 问题必须针对目标行业/品牌，非泛泛而谈 | 高 |
| B-02 | 问题必须是行业共性痛点，非个别案例 | 中 |
| B-03 | 问题与研究主题关联度必须明确 | 中 |

**输出模板**：
```
Q{编号}: 过于宽泛，任何行业都适用
Q{编号}: 仅适用于{品牌名}，非行业问题
```

---

## 二、覆盖度规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| B-04 | 必须覆盖商业模式/盈利模式维度 | 高 |
| B-05 | 必须覆盖市场格局/竞争态势维度 | 中 |
| B-06 | 必须覆盖用户增长/留存维度 | 中 |
| B-07 | 视行业补充：产品壁垒/合规风险等 | 低 |

**必检维度清单**：
- 商业模式/盈利模式
- 市场格局/竞争态势
- 用户增长/留存
- 产品/技术壁垒
- 风险/合规（视行业）

**输出模板**：
```
缺失: {维度名}维度
```

---

## 三、优先级规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| B-08 | P0必须是影响生存/核心增长的战略问题 | 高 |
| B-09 | P0数量不超过2个 | 中 |
| B-10 | P1为中期竞争力问题，P2为值得关注问题 | 中 |

**优先级判定标准**：
| 级别 | 标准 |
|------|------|
| P0 | 影响生存/核心营收，需立即决策 |
| P1 | 影响中期竞争力，需规划 |
| P2 | 值得关注，可后续跟进 |

**输出模板**：
```
Q{编号}: 应为P0，{原因}
Q{编号}: 应降为P2，非紧迫问题
```

---

## 四、独立性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| B-11 | 问题间不得实质重复（表述不同但本质相同） | 中 |
| B-12 | 问题间不得存在包含关系 | 中 |
| B-13 | 问题间不得有强依赖（A解决才能解决B） | 低 |

**输出模板**：
```
Q{编号}+Q{编号}: 实质重复
Q{编号}包含Q{编号}: 合并处理
```

---

## 五、可操作性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| B-14 | 问题必须可指导具体决策或行动 | 中 |
| B-15 | 问题必须有明确决策主体 | 低 |
| B-16 | 问题不可是纯现象描述 | 中 |

**输出模板**：
```
Q{编号}: 现象描述，非决策问题
Q{编号}: 过于抽象，无法行动
```
