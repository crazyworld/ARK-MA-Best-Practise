# Check 数据一致性规则

> **版本**: v1.0（2026-06-26）
> **状态**: 生效
> **来源**: 改编自 `KS_Validation_Rules/数据一致性规则.md`（D-09~D-23）
> **用途**: Check 角色在执行 Topic 专项清单时的补充判断规则，不替代 Topic 清单

---

## 一、数值一致规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-09 | 同一指标不同位置数值必须一致 | 高 |
| D-10 | 百分比加总必须等于100%（±1%容差） | 中 |
| D-11 | 计算结果必须与原数据一致 | 高 |
| D-12 | 同一单位体系内数值必须自洽 | 高 |

**输出模板**：
```
L{行号}+L{行号}: {指标}不一致({值1} vs {值2})
L{行号}: 占比加总≠100%(实为{值})
L{行号}: {计算项}计算错误(应为{正确值})
```

---

## 二、时效性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-13 | 财务数据时效≤1年 | 中 |
| D-14 | 市场数据时效≤6个月 | 中 |
| D-15 | 用户数据时效≤3个月 | 中 |
| D-16 | 数据时间点必须与报告要求匹配 | 中 |

**输出模板**：
```
L{行号}: 数据过期({数据年份}年数据)
L{行号}: 时效超限({实际时效} > {要求时效})
```

---

## 三、合理性规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-17 | 增长率应在合理范围（-50%~200%） | 中 |
| D-18 | 占比必须在0%-100%之间 | 高 |
| D-19 | 数值量级必须合理 | 高 |
| D-20 | 排名/排序必须符合数值大小 | 中 |

**输出模板**：
```
L{行号}: {指标}{值}异常
L{行号}: 占比{值}超范围
L{行号}: 量级存疑({值} vs 行业均值{参考值})
```

---

## 四、交叉验证规则

| 规则ID | 规则描述 | 严重度 |
|--------|----------|--------|
| D-21 | 核心数据需≥2个来源交叉验证 | 中 |
| D-22 | 不同来源数据差异≤10%视为一致 | 低 |
| D-23 | 差异>20%需标注并说明 | 中 |

**输出模板**：
```
L{行号}: 核心数据仅单一来源
L{行号}: 来源间差异{差异值}，需说明
```
