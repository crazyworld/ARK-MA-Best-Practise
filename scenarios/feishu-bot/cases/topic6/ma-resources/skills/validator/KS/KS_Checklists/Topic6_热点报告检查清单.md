# Topic6 · 热点报告 标注/报告质检清单

> **版本**: v1.1（2026-09-23）
> **适用阶段**: HC1（Phase C 小样本验收）/ HC2（Phase D 全量验收）/ HC3（Phase F 报告定稿）
> **适用对象**: Topic6 热点报告 标注结果（HC1/HC2）与最终飞书报告（HC3）
> **处理方式说明**:
>
> - HC1/HC2/HC3：Validator 由 Producer spawn 执行，结论通过 IM 回传至触发会话（Producer 展示内容前用户已能看到该结论）
> - HC3 仅第 1-3 条（版块合并完整性/输出格式/内容质量）可由 Validator 判断；第 4-5 条（营销案例截图、案例归类准确性）本质依赖视觉判断，Validator 不判断、不下结论，仍需人工在同一等待环节内自行核实
>   **问题分级**: P0 必须处理；P1 应当处理；P2 建议关注

---

## HC1：抽样数据标注结果检查

> 用户原始规则，逐字收录，不改写：

1. 数据质量判断：有没有明显的整个字段的空值、或者标注结果解析失败导致的大范围空白或者乱码、缺失
2. 对应的标注/事件聚类结果是否基本符合常识或标注目的
3. 对异常内容做判断：是应该修改提示词？还是仅对异常标注结果进行更正
4. 检查标注结果是否出现了未知的分类

**输出格式**：

```
结论: PASS / WARN / BLOCK
命中问题: [P0/P1/P2] 规则序号：问题简述
处理建议: 改提示词 / 改标注结果 / 无需处理
```

---

## HC2：全量数据标注结果检查

> 用户原始规则，逐字收录，不改写：

1. 数据质量判断：有没有明显的整个字段的空值、或者标注结果解析失败导致的大范围空白或者乱码、缺失（可能涉及到一些政治因素 敏感词等）
2. hc1 中出现的问题是否基本解决
3. 重新抽样、判断标注/聚类结果是否符合常识或标注目的（第一轮抽样可能有偶然性）
4. 对异常内容做判断：是应该修改提示词？还是仅对异常标注结果进行更正

**输出格式**：

```
结论: PASS / WARN / BLOCK
命中问题: [P0/P1/P2] 规则序号：问题简述
处理建议: 改提示词 / 改标注结果 / 无需处理
```

---

## HC3：对飞书报告做内容判断/定稿+人工截图

> 用户原始规则，逐字收录，不改写：

1. 审核版块合并是否正常，有无版块缺失/遗漏
2. 审核版块输出格式是否正常（会影响后续UI生成）
3. 审核内容质量（会去掉部分不合适/常识错误的内容）
4. 营销案例部分截图
5. 判断展现的案例是否归类准确，如果异常则寻找更佳的案例替补

**Validator 判断范围**：仅第 1-3 条。第 4、5 条本质依赖视觉判断（截图、案例归类比对），不委托 Validator——Validator 输出结论中必须显式声明未覆盖第 4-5 条，由用户在人工等待环节内自行核实，不得省略、不得暗示已核实。

**输出格式**：

```
结论: PASS / WARN / BLOCK
命中问题: [P0/P1/P2] 规则序号：问题简述
处理建议: 改版块结构 / 改格式 / 改内容 / 无需处理
覆盖说明: 本次检查仅覆盖第1-3条（版块完整性/格式/内容质量），第4-5条（营销案例截图、案例归类准确性）需人工核实
```
