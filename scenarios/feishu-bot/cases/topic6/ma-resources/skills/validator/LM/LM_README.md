# Validator 长期记忆说明

> **版本**: v0.1
> **更新日期**: 2026-03-27

---

## 目录结构

```
LM/
├── LM_README.md        # 本文件
├── Logs/               # 审计日志（按月归档）
│   └── {YYYY-MM}/      # 月度目录
│       ├── _index.md   # 月度索引
│       └── {日志文件}
├── 审计案例库.md        # 典型审计案例和判例
├── 校准记录.md          # 验证标准的调整记录
└── 误报记录.md          # 误报案例，用于优化
```

---

## 文件用途

| 文件 | 用途 | 更新时机 |
|------|------|----------|
| **Logs/** | 每次审计的完整记录 | 每次审计后（强制） |
| **审计案例库.md** | 典型问题案例，供后续审计参考 | 发现典型/复杂问题时 |
| **校准记录.md** | 规则调整记录，追踪标准演进 | 规则被修正时 |
| **误报记录.md** | 误报案例，避免重复误判 | 发生误报时 |

---

## 与KS的关系

| 类型 | 存放位置 | 特点 |
|------|---------|------|
| **规则和标准** | KS/ | 稳定、通用、可复用 |
| **案例和记录** | LM/ | 具体、时效性、持续积累 |

---

## 更新原则

### 审计案例库
- 记录典型问题，而非所有问题
- 每个案例包含：问题、原因、输出
- 定期归纳，抽象为KS规则

### 校准记录
- 记录每次规则调整
- 包含：调整前后、原因、效果
- 追溯规则演进历史

### 误报记录
- 记录被用户/专家否定的审计输出
- 分析误报原因
- 形成规避策略
