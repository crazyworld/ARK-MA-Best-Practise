## 品牌1.3数据与执行范围

使用Step4已保存`brand_stats.json`中的当前平台完整`cloud_word`和同范围可用`articles`，读取已确认品牌时间窗口、brand_keyword、brand_filterword、内容及情感范围。保存analysis_level=brand、brand_name及实际查询条件，通过需求适配工具交接。活动品牌/产品交集文件仅用于2.N.4③，不能作为品牌整体词表。品牌产品子范围仅在已有独立品牌范围词表且方案要求时展示，不新增取数任务。

词云分析在Step8按新Skill执行，Step10.5复用既有结果；有原帖按新抽样/证据契约核读，无原帖按全词表分析。两层均按调用补充写核心判断、证据和必要业务含义，不自动删词、不按频次合计计算噪音份额，不将所有品牌讨论归因于当前活动。

## 热帖成功配方解构 Prompt

> **用途**：分析 2.N.5 热门内容 Top 帖子的共性规律，生成「热帖成功配方」模块（洞察段 + 配方表）。
> **调用时机**：2.N.5 热门内容列表确认后，撰写 2.N.4 热帖模块时执行。

### 输入数据

```
活动名称：{activity_name}
分析平台：{platforms}
Top 帖子列表（取互动量前 10-15 条）：
[
  {
    "rank": 1,
    "platform": "小红书",
    "content_type": "PGC/UGC",
    "title": "...",          // 无标题时为空字符串或 null
    "content": "前200字...",
    "interaction": 12000,
    "url": "https://..."
  },
  ...
]
```

### Prompt 模板

```
## 角色
你是一位资深社媒内容策略分析师，擅长从高互动内容中提炼可复用的内容规律。

## 任务
基于以下「{activity_name}」活动的高互动内容列表，分析 Top 帖子的共性规律，
提炼出对未来内容创作有指导意义的「高互动内容规律」。

## 输入数据
{top_posts_json}

## 分析要求
1. 识别内容来源分布（平台构成 + PGC/UGC 构成），说明哪类来源的内容互动表现更突出；若数据中存在图文/视频字段则一并说明，否则跳过该维度
2. 归纳核心话题/主题（2-3个高频出现的内容方向）
3. 总结情感基调（激励/趣味/种草/测评/情感共鸣等）
4. 识别开篇钩子类型：分析 Top 帖子前 2-3 行/前 3 秒用什么方式抓住注意力，归纳出 1-3 种主要钩子类型，如：
   - **反差式**：「逛个超市居然……」「原来 XX 还能这样……」（用认知落差制造惊喜）
   - **惊叹式**：「救命！」「太会了！！」「直接震惊」（情绪词先行）
   - **场景代入式**：「周末去超市采购……」「带娃出门……」（日常场景开头引发同感）
   - **价格锚点式**：「不是迪士尼去不起，而是 XX 更有性价比」（价格比较触发点击）
   - **问题式**：「有人吃了嘛……」「到底要不要入手」（悬念/疑问引发评论）
5. 归纳叙事结构：提炼 Top 帖子中高频出现的内容展开逻辑，用「步骤一 → 步骤二 → 步骤三」形式描述（如「偶遇发现 → 沉浸体验 → 产品推荐」），并说明该结构为何有效
6. 综合以上，提炼出 1-2 句「高互动内容规律」作为核心洞察

## 输出格式
严格按以下结构输出，禁止出现「爆款配方」「解构」等内部分析语言：

### Top 帖子逐条拆解
| 排名 | 平台 | 互动量 | 标题 | 链接 | 内容类型 | 内容角度 | 开篇钩子 | 叙事结构 | 情感基调 | 互动归因 |
|-----|------|-------|------|------|---------|---------|---------|---------|---------|---------|
| 1 | [平台] | [数值] | [标题或内容前20字] | [url] | PGC/UGC | [≤10字] | [钩子类型] | [叙事类型] | [基调] | [≤15字] |
| 2 | ... |
（所有输入帖子各占一行，不省略）

### 主要叙事结构
**[结构名称]**：步骤一 → 步骤二 → 步骤三
[1-2 句说明该叙事结构为何有效、适合哪类内容场景]

（若有多种叙事结构，可列 1-2 条）

### 高互动内容规律（整体结论）
[核心洞察，1-2 句，含具体数据支撑，如"TOP15中有X篇为某类内容，平均互动量约X"]

[补充说明，2-3 句，覆盖内容来源、主题方向、情感基调、开篇钩子共性规律]

### 高互动内容共性
| 内容形式 | 核心主题 | 情感基调 | 代表帖互动量 |
|---------|---------|---------|------------|
| [形式] | [主题] | [基调] | [数值] |
| ... | ... | ... | ... |

> 注：本表与 KS_Report_Template.md §2.N.4 配方表对齐（4 列：内容形式/核心主题/情感基调/代表帖互动量）。「开篇钩子」字段仅出现在逐条拆解表中（11 列），不计入共性汇总表。

注意：
- 逐条拆解表每行必须覆盖所有输入帖子，不得合并或省略
- 「标题」：有标题填原标题；**无标题时截取 content 前 20 字代替，不得填「—」或留空**
- 「链接」：填输入数据中的 url 字段；无 url 时填「—」
- 「内容角度」控制在 10 字以内，描述该帖主要做了什么（如「主题店沉浸探店 + 新品种草」）
- 「开篇钩子」填具体类型（反差式/惊叹式/场景代入式/价格锚点式/问题式），无明显钩子填「—」
- 「叙事结构」填该帖所属的叙事类型名称（与「主要叙事结构」区块中的命名保持一致）
- 「互动归因」控制在 15 字以内，说明互动高的核心原因
- 叙事结构必须来自帖子内容的实际分析，不得编造
- 共性表 3-5 行，每行对应一种典型内容模式，是逐条拆解的归纳，不是重复列帖子
- 开篇钩子在共性表中控制在 5 字以内（如「反差式」）
- 不引用帖子原文，禁止出现用户账号名
- 禁止自行计算平台对比比值
- 若输入数据中无图文/视频字段，形式维度自动降级为平台/PGC-UGC，不得编造
```

## 经验总结合成 Prompt

> **用途**：基于全报告所有 Insight 段落，合成「三、经验总结」章节（成功经验 + 待改进问题 + 后续行动计划）。
> **调用时机**：Step 11 报告全部章节写完后，最后执行本 prompt。
> **质量红线**：每条经验/问题必须标注来源章节和具体数值，禁止空泛表述。
> **模型参数**：max_tokens ≥ 3000（输出较长，设置不足会截断）；推荐 claude-sonnet-4-6 或以上，确保长文本输出质量

### 输入数据

```
品牌名：{brand}
活动名：{campaign_name}
活动目标：{campaign_goal}
  ↑ 来源：需求确认单「活动核心目标」字段
    · 用户已填写 → 直接引用（如「产品种草」「品牌声量提升」）
    · 用户未填写 → 由 Planner 从报告数据中推断，格式为「{推断目标}（基于数据推断）」
      例：「联名 IP 内容营销 + 沃集鲜新品种草（基于数据推断）」
    · 此字段影响经验总结中「是否达成目标」类表述；若为推断值，相关表述须加注「基于数据推断」

[全报告 Insight 内容]
{report_insights}
（包含：1.2 口碑洞察 / 2.N.1 传播概况洞察 / 2.N.3 口碑洞察 / 
        2.N.4 达人层级洞察 / 2.N.4 UGC参与洞察 / 2.N.4 热帖洞察 /
        2.{N+1} 活动拉升效果洞察等）
```

### Prompt 模板

```
## 角色
你是一位资深营销复盘分析师，擅长从数据中提炼可操作的战略结论。

## 任务
基于「{brand} × {campaign_name}」的完整复盘报告洞察，
生成「经验总结」章节，包含三部分：成功经验、待改进问题、后续行动计划。

## 输入：报告洞察内容
{report_insights}

## 质量红线（P0，必须遵守）
- 每条成功经验和待改进问题，必须显式标注来源章节和具体数值
- 禁止空泛表述：
  ✅ 正确：「腰部达人单条内容的条均互动量是头部的2.3倍（来自活动内容分析达人层级效能模块），
            建议下次将腰部合作比例从30%提升至50%」
  ❌ 错误：「达人策略效果良好，建议继续优化达人组合」
- 行动计划项必须具体可执行，不允许「持续优化X」「加强Y」等模糊表述
- **待改进问题只针对活动执行层问题**（达人策略/活动机制/运营体验/内容形式等），不包含品牌外部负面事件（如食品安全监管事件等不受活动控制的因素）
- **禁止引用无来源的行业对比数据**（如「超行业一般水平」「通常为X%」等）——所有比较基准必须来自报告输入数据，不能凭模型知识补充
- **活动目标为推断值时**：若输入的 `{campaign_goal}` 含「（基于数据推断）」标注，则经验总结中涉及「是否达成目标」的表述须同步加注「基于数据推断」，不得将推断目标作为已确认事实呈现

严格按以下 Markdown 结构输出：

**经验 2：{...}**
数据支撑：...

**经验 3：{...}**
数据支撑：...

**问题 2：{...}**
**问题 3：{...}**

**立即行动**（下次活动前必须落实）

· {具体事项}

**长期策略**
· {方向性调整，1条}
```
