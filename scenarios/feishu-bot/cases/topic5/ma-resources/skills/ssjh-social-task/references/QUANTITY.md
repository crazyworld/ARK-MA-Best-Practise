# v0.10.1 数量偏差门禁

v0.10.2先按[任务优先估算规则](ESTIMATION.md)选择关系：本页双向容差适用于MATCHED及未分类历史任务；UPPER_BOUND不因实际少于估算阻断，UNCERTAIN仅记录比较告警（创建前需接受依据）。下载完整性和批准上限仍不放宽。

入口：`quantity_control.py`。下载前、缓存交付和本地再导出均执行门禁；Agent不自行计算或忽略等级。

## 两层数量校验

预检声量E与同条件任务可读量A可能因供应商数据库更新、索引等因素不同；差值本身不证明原因。取绝对差D=abs(A-E)，比例R=D/E，增加与减少同等判断。E>0时按以下顺序执行：

| 等级 | 默认条件 | 行为 |
|---|---|---|
| PASS | D≤20或R≤5% | 留存比较结果，继续 |
| BLOCKED | D>100且R>20% | 暂缓正常交付，反馈上游 |
| WARNING | 其余 | 继续，保留告警与交付说明 |

比例边界用Decimal比较，不用浮点近似作决策。恰好100条或20%不满足重大偏差条件。E=0时，A=0通过；0<A≤100告警；A>100阻断；比例为null。预检缺失不算通过，标UNVERIFIED并暂缓交付。正常新任务的零量预检仍不能创建。

**任务可读量与实际下载量必须严格相等**，ID唯一、分页完整性、文件哈希及导出回读继续检查；批准数量上限优先于容差。预检100、可读102、批准100仍停止。预检10,000、可读100是重大偏差；可读100、下载99是下载完整性错误，不能套用声量容差。

## 总量与分平台

总量和每个已选平台分别比较，以最严重等级处理，不能互相抵消。多平台预检从已校验哈希与查询指纹的precheck.json按平台汇总所有日期分段。同一已创建job的/count使用pLimit=1；微博/新闻/论坛用dataType=微博/新闻/论坛，其他支持平台用siteId：小红书146510、快手1334510、视频号25047925。站点计数不额外限制dataType，避免排除评论。原job已绑定关键词、排除词、日期、内容类型及广告/互动筛选，不重新编译不同查询或创建任务。

总量仍须与当前明确执行实例的dataCount一致才能开始下载。平台计数之和须等于整体可读量；平台预检之和须等于整体预检。缺失、集合不匹配或求和不一致标UNVERIFIED，保留原任务核对，不猜测拆分量。供应商接口的实际平台计数语义仍需真实验证，本版本使用官方快照契约和离线测试。

## 暂缓和恢复

重大偏差进入QUANTITY_REVIEW_REQUIRED，错误码VOLUME_DEVIATION_MAJOR；缺少核对证据使用QUANTITY_COMPARISON_UNVERIFIED。retryable=false、route_to=upstream_agent、upstream_action=HOLD_DELIVERY_AND_REVIEW_ORIGINAL_TASK。execute不自动推进此状态，不能用download/resume/export绕过。

上游核对后可显式复查原任务：

```text
python ssjh_social_task.py --action review-quantity --config TASK_CONFIG --run-dir RUN_DIR
```

此动作查询既有job状态和数量，使用原条件及保存阈值重新判断；本动作不调用声量预检、不创建任务、不下载或导出。复查通过后，再执行原任务的正常恢复。没有强行放行开关；持续重大偏差继续暂缓。不得改state.json解锁、删除缓存或换请求重新创建。

## 配置与记录

`risk.volume_deviation`的normal_absolute/normal_ratio/major_absolute/major_ratio默认为20/0.05/100/0.20；省略时采用默认。类型、非有限数、负数、未知键及阈值顺序错误均拒绝。首次运行保存规范化阈值，同一运行不可中途改变；旧付费任务采用默认，不静默应用宽松配置。阈值是本地质量规则，不是供应商数量保证或生产统计置信区间。

quantity-review.json及state保存查询、当前实例、基数、实际数和策略绑定，校验报告哈希；公开信封data.volume_comparison与耗时/交付日志仅携带比较白名单字段，不包含费用、凭证或原文。报告不推断差异原因。中间产物默认由上游消费记录，不自动发外部消息。

已完成缓存本地重新评估，不联网。旧单平台缓存使用保存的预检/任务量；旧多平台缓存缺少可验证的平台计数时暂缓，可显式复查原job补证。既有原始文件及结果不覆盖。旧版派生导出的validation.json结构与本版不同可能触发CACHE_DERIVED_QUALITY_MISMATCH，此时保留旧产物，完成数量核对后用新输出路径重新导出，不修改历史报告骗过校验。
